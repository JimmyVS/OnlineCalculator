# 🧮 Calculator App

A simple and stylish calculator built with **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations and features a responsive, modern UI.

## 🚀 Features

- Basic arithmetic: Addition, Subtraction, Multiplication, Division
- CE (Clear Entry) and C (Clear All) functions
- Backspace functionality
- Keyboard input disabled for clean UI-only interaction
- Responsive and mobile-friendly design
- Light/dark-inspired modern aesthetics
